# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-03-22

- Renamed the main script to `Export-AlfrescoFolderTree.ps1`
- Replaced hardcoded values with parameters and `PSCredential`
- Added pagination support, retries, ZIP output, safer file naming, and skip-existing mode
- Introduced a richer console UI with progress and summary output
- Reworked the README and repository presentation in English
- Added a GitHub Pages landing page with crawl-friendly metadata
- Added repository topics, homepage, and improved description
- Added a validation workflow for script and docs
